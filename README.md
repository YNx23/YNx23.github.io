## 🗺️ Learning Paths & Workflows

### 🌊 Path 1: Flood & Disaster Risk Mapping Specialist
*Est. Time: 6–8 Weeks | Focus: Technical GIS & Remote Sensing*
1. **Desktop Foundations:** Master basic vector/raster processing with `OSM Basics` and `QGIS for Field Operations` (UN Mappers).
2. **Automated Analysis:** Learn spatial scripting and Python dataframes via `Automating GIS Processes` (Univ. of Helsinki).
3. **Cloud Remote Sensing:** Ingest satellite imagery and compute spectral indices in `Planetary Scale Earth Observation with Google Earth Engine`.
4. **Impact Application:** Apply hazard modeling and open risk data via the `GFDRR E-Learning Platform` (World Bank).

---

### 🌱 Path 2: Climate Policy & Youth Advocacy
*Est. Time: 3–5 Weeks | Focus: Governance, Communication & Action*
1. **Terminology:** Build a precise foundational vocabulary using `Climate Words`.
2. **Media Literacy:** Learn to identify greenwashing and assess data integrity with `Navigating Climate Information` (UNESCO).
3. **Systems Thinking:** Explore behavioral interventions and policy mechanisms in `Systems Change x Behavioural Science` (UN-Learn).
4. **Global Action:** Join international delegation working groups via `YOUNGO` or `CYMG`.

## 🤝 How to Contribute

We welcome community contributions! Please review our [CONTRIBUTING.md](CONTRIBUTING.md) guidelines before submitting a Pull Request.

### Submission Guidelines:
1. **Open Access:** Resources must offer free access or a permanent, un-monetized open tier.
2. **Reputable Authoring:** Material should be created by established academic institutions, UN bodies, NGO networks, or recognized open-source leads.
3. **Domain Relevance:** Must fall strictly within GIS/Geospatial, Climate Science/Policy, or Disaster Management.

To suggest a resource, submit a GitHub Issue using our **[Resource Suggestion Template](../../issues/new?template=resource_submission.yaml)**.
