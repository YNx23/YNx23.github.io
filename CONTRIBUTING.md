# Contributing Guidelines

Thank you for helping us maintain and expand this learning directory!

## Quick Rules:
- Check existing listings before submitting to prevent duplicates.
- Ensure all links point directly to the main landing page of the resource.
- Keep descriptions clear, concise, and objective.

## How to Submit:
1. Open an issue using the [Resource Submission Template](.github/ISSUE_TEMPLATE/resource_submission.yaml).
2. Or submit a Pull Request directly editing `README.md` following the established markdown table syntax.
